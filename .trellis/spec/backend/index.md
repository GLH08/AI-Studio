# Backend Development Guidelines

> Server-side conventions for AI Studio — a single-file Express.js app (`app.js`).

---

## Overview

The backend is one ESM module, `app.js` (~1300 lines), organized into banner-comment
sections (`// ==================== Section ====================`). There is no framework
beyond Express, no ORM, and no TypeScript. State lives in a JSON file (`data/db.json`);
media is generated by calling external provider APIs and optionally re-hosted on Chevereto.

`app.js` is both the server and a testable module: `app.listen` runs only when the file is
executed directly (`isMainModule`, `app.js:20`), and the bottom `export { ... }` block
(`app.js:1328`) exposes `app` plus pure helpers so tests can import them without starting a
listener.

## Conventions At A Glance

- ES modules (`"type": "module"` in `package.json`); use `import`, not `require`.
- 4-space indentation, single quotes, semicolons (enforced by `eslint.config.js`).
- Configuration comes exclusively from environment variables — no config files, no secrets in code.
- Keep new server logic inside `app.js` in the matching banner section unless a helper is genuinely reusable and pure (then also add it to the export block if tests need it).

**Language**: All documentation is written in **English**.
